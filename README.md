# DEVONIC BOT

بوت واتساب مبني على Node.js ويعمل على Termux.

## تشغيله على Termux

نفّذ الأوامر التالية بالترتيب:

```bash
pkg update -y && pkg upgrade -y
pkg install -y git nodejs-lts

git clone https://github.com/moa926032-hub/BOT_Devonic.git
cd -- BOT_Devonic
npm install

# اكتب رقم واتساب بصيغة دولية بدون علامة +
export BOT_PHONE=201XXXXXXXXX

# اختياري: منع أندرويد من إيقاف العملية أثناء التشغيل
termux-wake-lock

npm start
```

في أول تشغيل سيظهر كود الربط بالشكل:

`DEVO-NIC1`

من واتساب افتح:

**الأجهزة المرتبطة ← ربط جهاز ← الربط برقم الهاتف**

بعد نجاح الربط، يحفظ البوت الجلسة داخل مجلد `session` ولن يطلب كودًا جديدًا في كل تشغيل.

## تغيير رقم البوت

غيّر الرقم قبل التشغيل:

```bash
export BOT_PHONE=201XXXXXXXXX
npm start
```

أو ضعه في نفس جلسة Termux قبل كل تشغيل. الرقم يجب أن يكون بدون مسافات أو علامة `+`.

## إعادة الربط من جديد

لا تحذف مجلد `session` إلا إذا كنت تريد تسجيل رقم مختلف أو إعادة ربط الحساب:

```bash
rm -rf session
npm start
```

## الاشتراك الإجباري

قبل استخدام أوامر البوت، يجب أن يكون المستخدم مشتركًا في الجروب المحدد داخل إضافة الاشتراك الإجباري. المستخدم غير المشترك يستلم رابط الجروب ويتوقف أمره حتى ينضم.

## ملاحظات

- شغّل `npm start` من داخل مجلد المشروع.
- لا ترفع مجلد `session` إلى GitHub لأنه يحتوي على بيانات جلسة واتساب.
- لإيقاف التشغيل استخدم `Ctrl + C`.
